# Part
Parts is Luduvo's prefab for the basic building block of a game. 

## Constructor(s)

- `Prefab.spawn("Part")`

!!! note
    Parts are automatically parented to the 3D world.

## Components

### Removable

- `Position`
- `Rotation`
- `Scale`
- `Data`
- `PrefabInstance`
- `Shape`
- `RigidBody`
- `BrickColor`
- `Material`

### Permanent

- `Attributes`
